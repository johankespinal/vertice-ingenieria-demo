# Vértice Ingeniería — Demo corporativa

Concepto de sitio corporativo diseñado para el portafolio de **Johan Espinal / Sistemas JK**. Inspirado en los principios visuales de los estudios de ingeniería tradicionales: sobriedad, legibilidad, fotografía arquitectónica, jerarquía clara y confianza.

## Incluye
- Portada con fotografía arquitectónica, identidad original y mensajes de posicionamiento.
- Cuatro áreas de especialidad con navegación interna.
- Secciones de presentación, metodología, servicios y proyectos conceptuales.
- Formulario de demostración con validación local, **sin transmisión ni almacenamiento de datos**.
- Diseño adaptable a escritorio, tablet y móvil y navegación accesible.
- HTML, CSS y JavaScript, sin frameworks, backend ni bases de datos.

## Publicación
1. Crea un repositorio público en GitHub, por ejemplo `vertice-ingenieria-demo`.
2. Sube `index.html`, `styles.css` y `app.js` a la raíz de la rama `main`.
3. En **Settings → Pages**, elige **Deploy from a branch → main → /(root)**.
4. La dirección quedará como `https://johankespinal.github.io/vertice-ingenieria-demo/` si ese es el nombre del repositorio.

## Aviso
Vértice Ingeniería es una **empresa ficticia** creada exclusivamente como ejercicio de diseño web y pieza de portafolio. Los proyectos visuales son ilustrativos, no representan trabajos ejecutados. Las fotografías de Unsplash se cargan desde un proveedor externo y necesitan conexión. No se incluyen credenciales, licencias profesionales, cifras de negocio o testimonios reales. Para su uso comercial es necesario reemplazar el contenido, integrar los formularios y preparar avisos legales y privacidad.
